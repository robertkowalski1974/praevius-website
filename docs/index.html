Praevius is construction programme software you can talk to. Import an MS Project, Asta Powerproject or Primavera P6 programme into the browser, update it by voice or keyboard, check the critical path, and export it for MS Project or Primavera. It covers Gantt, critical path and float, baselines, progress and validation, with an AI assistant that makes changes from plain English and a report on every import and export. Made for subcontractors, package planners, site managers and small main contractors. One price per company with no per-user fees: a free plan, and paid plans from $99/month. Cost Control runs on the same platform from the Essential plan. Built by quantity surveyors with 20 years in construction.

Import the Programme You Already Have

Start from the file the main contractor sent you. Praevius reads MS Project, Asta Powerproject and Primavera programmes, and tells you exactly what came across before anything is saved.

Formats In

MS Project .mpp and .xml, Asta Powerproject .pp and Primavera .xer, up to 20 MB. Each import arrives as a new draft, so it never overwrites your live programme.

A Report Before You Confirm

See the task and link counts, how many dates move, and what could not be carried. WBS, all four link types with lags, constraints, deadlines, milestones, calendars, holidays, progress, activity codes and custom fields come across.

Formats Out

Export for MS Project (XML) or Primavera (XER), or as a PDF A3 or Excel file for the main contractor. The export report lists anything the target format cannot hold.

Plain limits: up to 2,000 tasks per programme (150 on Free). No resource or cost loading. No native .mpp or .pp export; Asta Powerproject can import the MS Project XML, and may convert calendars. Task calendars, split tasks, resources and baselines stored in the file are not imported, and the report lists them.

Just Say It

Update the programme the way you would explain it on site. Speak or type, and the assistant makes the change and shows you what moved.

1. You Say

“Push frame out a week.”

2. The Programme Updates

Frame moves a week later. The tasks linked after it move with it, the critical path recalculates, and the assistant tells you on screen what changed and where the finish date now sits.

3. Not Right? Undo

Ordinary edits apply at once and can be undone, up to the last 25 steps. Bigger changes, such as deleting more than 10 tasks, an import or a restore, are proposed first and run only when you confirm.

It Understands Site Language

  • “Piling started on 3 March and is 60% done.”
  • “Shut the site for Christmas.”
  • “What’s driving the finish?”

Or start from nothing: “Create a programme starting next Monday: groundworks 3 weeks, then frame 8 weeks, then fit-out 6 weeks.” It asks for any missing durations and lists every assumption it makes.

How Voice Works

  • Click the mic in the assistant panel and speak.
  • Watch the live transcript and edit it if a word is wrong.
  • It sends after about two seconds of silence, with a visible countdown.
  • Replies appear on screen. Say “yes, go ahead” or “cancel” to answer a proposal.
  • Works in Chrome, Edge and Safari with an internet connection, in English and Polish.
  • Typing always works, in every browser.

The Planning Tools You Use Every Week

Critical path scheduling, a Gantt chart and a keyboard grid that works like MS Project. Included in every plan.

Critical Path and Float

See which tasks drive your finish date. Critical tasks are marked, with total and free float, and the assistant explains the driving predecessors in plain English.

Gantt and Keyboard Grid

Drag to move, stretch and link on the Gantt, or type fast in the grid: 3, 5SS+2d for links, 2w or 2ed for durations. Edit many tasks in one step.

Baselines and Progress

Baseline the contract programme, compare against it or a saved version, and record progress by status date, percent complete and actual dates.

Validate Before You Issue

Catch open ends, negative float and constraints that fight the logic before the main contractor does.
